# 综合靶场平台权限清单

平台角色为**普通用户**（`user`）和**管理员**（`admin`）。平台超管是带额外平台管理权限的管理员。表中的「本空间」指当前云厂商与主账号对应的云账号工作空间；「本人」指资源所有者。独立实例的旧记录没有所有者时，才按创建人判断。已发布资源只在同一工作空间内共享；历史待核验空间只读。按钮可用性还取决于云厂商能力、资源状态、引用关系及必要的确认。

## 登录和工作台

| 功能 | 普通用户 | 管理员 |
|---|---|---|
| 平台登录、会话续期、退出 | 可用自己的启用账号登录、续期与退出。账号被禁用后不能继续访问业务 | 同普通用户 |
| 顶栏身份与当前工作空间 | 查看自己的用户名、角色、当前云厂商和云账号摘要；可重试加载当前空间 | 同普通用户；仅平台超管可跨空间切换 |
| 导航入口 | 镜像中心、实例管理、编排中心、编排实例 | 另有用户管理、账单费用、基础配置 |
| 主题与通用表格控件 | 可切换经典、赛璐璐和数据密集主题；在有权访问的列表中搜索、筛选、分页、调整每页条数、刷新和重试 | 同普通用户，列表数据范围按模块权限扩大 |
| 未登录访问 | 可打开登录页和公开健康检查；业务列表、详情及操作需登录 | 同普通用户 |

## 镜像中心

| 功能 | 普通用户 | 管理员 |
|---|---|---|
| 平台镜像列表 | 浏览本空间已发布且来源可用的虚拟机镜像及已收录容器；可按名称、ID、类型、创建人或标签筛选。列表不显示状态列 | 同普通用户，另可查看平台视图中的暂不可用条目 |
| 平台镜像：创建实例 | 可从符合条件的已发布虚拟机镜像创建独立实例；容器镜像暂不用于开通实例 | 同普通用户 |
| 平台镜像：维护 | 无重命名、改标签、撤回或删除入口；本人镜像的维护入口在「我的镜像」 | 可重命名平台镜像、维护标签；对有所有者的已发布镜像可用「删除(回退为私有)」。该动作保留云镜像和原归属。无个人归属的目录条目没有回退对象；可移除已收录的容器条目 |
| 我的镜像：列表、状态和创建 | 只看自己的镜像。状态为「私有」或「已发布」，导入或打包进度在名称下显示。来源可用时可创建实例 | 同普通用户；管理员的「我的镜像」也只列本人 |
| 我的镜像：重命名、发布、撤回 | 可操作本人镜像。发布和撤回后同步更新平台列表及个人状态。被已发布拓扑引用的镜像受撤回保护 | 同普通用户 |
| 我的镜像：云端删除 | 只可删除来源可核验的本人导入或打包镜像；模板和活动实例引用会拦截删除。云端确认删除后移除平台记录，关联快照保留。个人公共镜像收录仅移除收录关系 | 同普通用户；此入口不能删除他人的私有镜像 |
| 上传、导入进度与失败重试 | 可在支持导入的空间上传系统盘镜像，填写名称、系统、格式、架构、磁盘与默认配置；查看本人导入任务、重试可恢复失败 | 同普通用户。后台可按权限查看或处理本空间导入任务的指定记录，页面的导入列表只列本人 |
| 镜像标签 | 查询、筛选标签；在「我的镜像」给本人镜像添加或移除已有标签 | 可新建、删除本空间标签定义，并维护已发布资产的标签；个人页使用已有标签的规则与普通用户相同 |
| 镜像导出记录 | 查看、搜索和刷新本人打包任务及失败原因；核验并恢复符合条件的任务 | 同样操作，可查看本空间打包任务。入口位于镜像中心、实例管理及编排实例详情 |
| 墨攻镜像中心 | 在支持的阿里云空间浏览、筛选目录，逐条收录符合条件的虚拟机或容器 | 同普通用户；目录同步及后台的容器批量收录预览、执行仅管理员可用，并受空间绑定限制 |
| 云上镜像来源 | 无入口及目录查询、同步、收录权限 | 浏览、搜索、同步当前厂商的公共、自定义镜像，收录可用条目；按目录现有规则删除符合条件的自定义云镜像，可选择回收已验证属于该镜像的快照 |
| ACR 容器镜像、腾讯云镜像目录 | 无 | 阿里云可查看、搜索和同步 ACR 实例、仓库、标签及地域；腾讯云可查看和同步当前账号的公共及自定义镜像 |
| 后台镜像管理 | 可使用授权工具发布、撤回或删除本人镜像。已有来源证明的本人打包镜像可通过专用回收操作处理其快照 | 可撤回其他用户已发布的镜像，不能通过「我的镜像」的云端删除操作删除他人资产。云上目录管理和已验证打包快照的回收继续按原权限执行 |
| 手动启用／禁用镜像 | 已移除 | 已移除。镜像仍按来源、导入和清理状态判断能否用于创建 |

## 实例管理（独立实例）

| 功能 | 普通用户 | 管理员 |
|---|---|---|
| 当前实例、实例历史、批次 | 只看本人当前实例、历史和批次；可搜索实例名、展开批次、分页及查看生命周期时间 | 默认仅本人；可切换「全部用户」查看本空间的当前实例、历史和批次 |
| 创建单台或整批 | 可选已发布或本人可用镜像，查看可售规格，填写名称、主机名、CPU、内存、磁盘、数量、密码、备注和到期时间。结果未确认时可查询原请求 | 同普通用户；从个人镜像创建也须是本人镜像 |
| 查看详情、云端状态、访问凭据 | 查看本人实例的详情和 IP，可按需查看或复制保留的登录凭据；打开符合条件的 VNC。后台支持只读核验对应云实例 | 同样操作，范围为本空间实例 |
| 导出 | 可导出本人批次及页面提供的单台／批次历史信息；CSV 可包含保留的登录账号和密码 | 同样操作，范围为本空间实例。MCP 按批次导出支持管理员显式选择「全部用户」 |
| 重启、二次打包和任务核验 | 可重启本人运行实例、二次打包镜像、查看导出记录和核验原打包任务 | 同样操作，范围为本空间实例；打包归属按来源记录确定 |
| 节省停机、恢复和预约 | 阿里云可对符合条件的本人单台或整批立即停机、预约、修改或取消预约、恢复开机，查看和核验原启停任务 | 同样操作，范围为本空间实例和批次 |
| 修改回收时间 | 可对符合条件的本人单台或整批预览并确认修改，查看修改记录及核验失败任务 | 同样操作，范围为本空间实例和批次 |
| 销毁和失败处理 | 可销毁本人单台或整批，重试失败回收；创建失败可查看历史，后端按状态提供重试 | 同样操作，范围为本空间实例和批次 |
| 共享网络 | 开通时可使用平台分配的共享网络；无显式管理权限 | 后台可查询、创建或确保共享网络，登记本轮回收并确认回收符合条件的空闲网络 |

## 编排中心（模板）

| 功能 | 普通用户 | 管理员 |
|---|---|---|
| 平台拓扑：列表与详情 | 默认显示「平台拓扑」，浏览本空间已发布模板；可按名称、创建人筛选。消费的是发布版本 | 同普通用户；没有「全部拓扑」入口 |
| 平台拓扑：创建实例和复制 | 可从发布版本创建单套或多套实例，或复制为自己的私有模板 | 同普通用户 |
| 平台拓扑：维护 | 无「进入编排」、修改原模板、回退或删除入口 | 可将已发布模板回退为私有或删除。没有「进入编排」或编辑他人原稿入口；未销毁实例引用会拦截删除 |
| 我的拓扑：列表、新建与编辑信息 | 只看自己的私有或已发布模板；可新建私有模板、编辑名称和描述、进入编排、复制或删除自己的模板 | 同普通用户；管理员也不能访问他人未发布模板 |
| 画布工具 | 在本人模板上添加路由器、交换机和主机，选择、拖动、连线、删除、撤销、重做、自动布局，绘制和调整区域；可缩放、适应视图、使用导航图和全屏 | 同普通用户 |
| 设备和网络属性 | 编辑本人模板的网段、ACL、NAT、端口映射、主机镜像、规格、主机名、网卡、IP、安全组、DNS 和初始化配置 | 同普通用户 |
| 检测保存、发布与回退 | 可检测并保存自己的草稿、发布或回退；发布版本引用的虚拟机镜像必须已发布 | 同普通用户。平台视图的管理员撤回权限不授予草稿编辑权 |
| 从本人模板创建实例 | 可从自己的可用模板创建实例 | 同普通用户 |
| 拓扑概览 | 查看区域、主机和节点数量，单行显示 | 同普通用户 |
| 墨攻场景档案（后台） | 无 | 仅部署已配置档案，且当前工作空间和档案指定的管理员都匹配时可查阅 |

## 编排实例（运行环境）

| 功能 | 普通用户 | 管理员 |
|---|---|---|
| 创建单套或整批 | 从「我的拓扑」或「平台拓扑」中的可用模板创建，填写名称、数量和到期时间；结果未确认时可查询原请求 | 同普通用户；创建入口受云厂商能力限制 |
| 当前列表、历史和批次 | 只看本人，支持状态、名称筛选、分页及批次展开 | 默认仅本人；可切换「全部用户」查看本空间记录 |
| 概况、节点目录与诊断 | 查看本人实例的状态、来源模板、公网入口、到期时间、网络规则、节点及其地址；后台可只读查看实例的网络诊断与作业证据 | 同样操作，范围为本空间实例 |
| 凭据、VNC 和靶场信息导出 | 查看或复制本人节点保留的登录信息，打开符合条件的 VNC；导出本人单套或整批节点、地址、端口映射及到期时间，凭据默认不导出 | 同样操作，范围为本空间实例及批次 |
| 节点运维 | 可操作本人实例的符合条件节点：开机、关机、重启、二次打包、核验 DNS；阿里云可预览并确认系统盘重置；后台可重新下发 DNS、只读核验打包参数 | 同样操作，范围为本空间实例，受厂商及节点状态限制 |
| 运行拓扑与变更 | 查看本人运行拓扑；允许编辑时可调整画布、区域、节点和规则，保存草稿、预览并确认应用。已部署主机的镜像、规格等字段受保护 | 同样操作，范围为本空间实例，同样遵守字段和状态限制 |
| 另存、丢弃与回写草稿 | 可把本人实例已保存的草稿另存为新的私有模板；后台可丢弃草稿、在有权维护原模板时回写 | 同样操作，实例范围为本空间；回写原模板仍须具有该模板的编辑权 |
| 节省停机、恢复、预约和改期 | 阿里云可对符合条件的本人整套或整批操作，查看和核验启停及修改回收时间任务 | 同样操作，范围为本空间 |
| 销毁与失败恢复 | 可销毁本人单套或整批、查看回收进度和失败原因，按状态重试创建或回收、查询原请求 | 同样操作，范围为本空间 |

## 用户管理

| 功能 | 普通用户 | 管理员 |
|---|---|---|
| 用户清单、搜索、统计、复制登录账号 | 无模块权限 | 可查看和管理本空间业务用户；平台超管不列入业务用户清单 |
| 创建用户、角色切换 | 无 | 可创建普通用户或管理员，修改本空间业务用户角色 |
| 启用、禁用、重置密码 | 无 | 可启用、禁用或重置本空间业务用户。最后一名启用管理员不可降级或禁用；业务管理员不能管理平台超管。平台超管可通过后台重置自己的密码 |

## 账单费用和资源告警

| 功能 | 普通用户 | 管理员 |
|---|---|---|
| 账单页面与费用范围 | 无账单页面，也无独立个人账单入口 | 查看本空间已归属平台的用户费用及平台公共费用 |
| 阿里云账目、筛选、详情和刷新 | 无 | 可按用户、账期和出账状态筛选，展开实例批次，查看费用组成、用量、计费依据、关联资源、操作记录和待核对项，刷新页面 |
| 腾讯云／旧版账单 | 无 | 查看费用概览、用户费用、平台费用、分组明细、待补齐与异常提示；账号支持时可手动同步 |
| 导出账单 | 无 | 按账期导出用户汇总、指定用户明细和平台费用 CSV |
| 后台账单诊断和对账 | 无 | 可查询异常、只读核对资源月账、发起当前空间允许的账单同步或资源对账、查询对账任务；启用或切换账单写入方式及查看仅供超管的比较证据限平台超管 |
| 阿里云专用 OSS 桶费用归属（后台） | 无 | 可查询已登记归属；创建专用导入桶、声明或结束专用归属仅平台超管 |
| 资源告警 | 无 | **仅平台超管**：查看、筛选和刷新当前空间告警，核对巡检状态及失败原因，设置跟随账号，预览并确认符合条件的残留资源回收 |

## 基础配置与后台自动化

| 功能 | 普通用户 | 管理员 |
|---|---|---|
| 基础配置、账号摘要、地域和规格 | 无配置页面。顶部可查看当前空间，创建表单可查询所需的配置摘要及可售规格 | 查看所属空间的云账号清单、厂商标签、默认地域和可用区、账号启用状态及可售机型 |
| 跨账号切换、历史空间 | 无 | **仅平台超管**：在已绑定空间之间切换，可进入有权限的历史空间只读查看 |
| 账号绑定与配置 | 无 | **仅平台超管**：验证并绑定或更新阿里云／腾讯云账号、默认地域和可用区、凭据及导入桶配置；按条件删除非当前账号的绑定。删除绑定不直接删除云资源 |
| 异步作业、操作结果和证据 | 查询本人实例关联的创建、变更、回收作业及步骤，按权限查看脱敏证据和失败原因 | 同样操作，范围为本空间实例和作业 |
| MCP 连接、工具查询和调用 | 使用自己的启用身份，只能调用角色、授权范围和资源归属均允许的工具 | 同样校验；可使用本角色和当前空间允许的管理工具。仅超管操作仍需超管身份 |
| 任务调度与自动回收 | 可设置本人实例的允许到期时间并查看结果；后台按已受理任务的冻结账号执行 | 同样操作，可管理本空间符合条件的实例；切换账号不会改变已受理任务的原账号 |

涉及运行、发布、删除、回收和敏感导出的操作仍受服务端的状态、版本、确认和幂等检查。网页入口与后台工具并非逐项相同；MCP 的具体工具、参数和授权范围参见[镜像中心](../../skills/references/products/image-center.md)、[实例管理](../../skills/references/products/instance-management.md)、[编排中心](../../skills/references/products/range-authoring.md)、[编排实例](../../skills/references/products/range-instances.md)、[用户管理](../../skills/references/products/user-management.md)、[账单](../../skills/references/products/billing.md)、[资源告警](../../skills/references/products/resource-alerts.md)及[基础配置](../../skills/references/products/settings.md)。
