# 管理工作台组件与页面统一设计

**状态：** 已确认  
**日期：** 2026-07-23  
**方向：** A「统一工作台」

## 目标

统一管理后台中下拉框、模板编辑器和编排实例历史/详情页的视觉语言，使它们与现有列表工作台、按钮和状态组件保持一致。

本次改造覆盖：

1. 所有原生 HTML `<select>`：账单费用、镜像上传、用户管理、模板属性面板。
2. 新建和编辑编排模板的顶部工具栏、资源面板、拓扑画布、属性面板及其操作控件。
3. 编排实例的实例历史列表和查看详情页。

不改变模板数据结构、实例生命周期、API 契约、路由和现有操作语义。

## 统一 Select

项目已有 shadcn/Radix `Select`，本次直接复用而不新增组件库依赖。

### 基础样式

- Trigger 使用 32px 高、6px 圆角、实线边框和白色背景，不采用浏览器原生菜单或胶囊外观。
- 选项面板与 Trigger 同宽，6px 圆角、细边框、轻阴影；当前选项使用现有浅蓝选中态。
- Label 保持 12px 中性色，与账单筛选和模板属性字段一致。
- 统一使用 Lucide `ChevronDown` 和 `Check`；键盘操作、焦点环与禁用态由 Radix 负责。

### 空值契约

Radix `SelectItem` 不接受空字符串 value，但现有表单存在“全部用户”“未连接交换机”“未选择”等空值。共享字段适配器内部使用不可见的非空 sentinel，并仅在对外回调时恢复为 `''`。这样保持现有 API payload 和状态更新逻辑不变。

### 接入方式

- 新增受控的 `AdminSelectField`，负责 label、aria label、空选项、触发器宽度和字符串选项渲染。
- 账单、镜像上传和用户管理使用该组件，移除浏览器原生 `<select>`。
- 模板属性面板使用同一语义适配器，但保留本地字段布局、动态节点选项和现有更新函数。
- 现有分页和云配置已经使用 shadcn Select，会随基础样式收口而同步一致。

## 编排模板工作台

模板编辑器继续保持三栏信息架构：资源面板、拓扑画布和属性面板。

### 顶部工具栏

- 标题区域显示模板名称和状态 Badge（私有/已发布）。
- “删除选中”使用危险次级按钮；“检测与保存”使用 outline；“发布到平台”是唯一主按钮。
- 使用已有 `Button`、`Badge` 和稳定按钮高度，移除模板编辑器独有的原生 button 外观。

### 三栏面板

- 三个区域使用同一细边框、白色面板和紧凑标题行；不再存在不同圆角、阴影或标题字重。
- 资源卡、画布空状态和属性占位态采用现有后台的静态层级，不增加装饰性背景。
- 模板属性中的所有选择字段改为统一 Select；选项变化继续调用当前节点更新回调。

## 编排实例历史与详情

实例历史列表继续使用 `AdminPageHeader`、`AdminListToolbar` 和 `AdminDataTable`，并加强与详情页的连续性：

- 历史 tab、搜索、分页和“查看详情”按钮沿用统一列表工具栏和 action 样式。
- 历史空状态、错误状态和行操作不引入额外定制卡片。

实例详情页从旧的模板工作台类名迁移到管理工作台语言：

- 使用 `AdminPageHeader` 显示“实例详情”、实例/场景上下文和返回操作。
- 概览信息在一个无嵌套卡片的响应式字段网格内展示；历史实例保留“只读历史”状态。
- “节点目录 / 拓扑结构”改用现有线性 Tabs。
- “保存草稿”“应用变更”“更新编排拓扑”改为已有 Button，主次关系保持一主两次。
- 节点目录、拓扑画布和二次打包镜像对话框仅调整容器、标题和控件样式，不改变节点操作、草稿保存或拓扑同步行为。

## 可靠性与测试

1. 为共享 Select 字段添加单元测试，覆盖空值映射、禁用态、当前项和键盘可访问名称。
2. 更新账单、用户管理、镜像中心和模板编辑器测试，使用 Radix Select 的按钮/选项交互代替 `fireEvent.change` 原生选择框。
3. 继续覆盖模板属性的未选择交换机、协议、动作和镜像选择；验证提交 payload 保留原本的空字符串。
4. 更新编排实例历史和实例详情测试，验证统一标题、Tabs、按钮 variant 与只读历史状态。
5. 在 Docker 容器中构建 Web、运行聚焦测试，并截图检查账单下拉、模板三栏、实例历史与详情的桌面/移动布局。

## 验收标准

1. 截图所示的账单用户筛选不再出现浏览器原生菜单，展开后使用浅蓝当前项、细边框和稳定宽度。
2. 项目中上述原生 `<select>` 均被 shadcn/Radix Select 替换，空值与原功能一致。
3. 新建模板页的按钮、状态、三栏标题与面板边界属于同一管理后台视觉语言。
4. 编排实例历史与详情页的标题、Tabs、按钮和概览字段具有和列表页一致的密度与层级。
5. 现有模板检测、发布、实例详情、节点操作和历史只读行为不回归。
