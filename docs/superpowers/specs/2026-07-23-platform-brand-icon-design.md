# 平台品牌图标与 Favicon 设计

**状态：** 已确认  
**日期：** 2026-07-23  
**方案：** A「结构盾牌」

## 目标

为云上综合靶场平台补齐统一的品牌图标，使它同时出现在：

1. 管理后台左侧导航顶部的“综合靶场平台”名称左侧。
2. 移动端导航抽屉标题中。
3. 浏览器标签页 favicon。

标识应在管理平台现有的白色、深蓝文字、浅蓝选中态语言中显得克制、清晰，不改变导航与内容区布局。

## 标识设计

图标使用圆角方形的深蓝底色（`#1d56a7`）与白色“结构盾牌”线条：

- 外轮廓是简洁的盾牌，表达靶场的安全边界。
- 盾牌内部保留一个矩形结构单元，暗示受控的云上资源与编排单元。
- 不使用渐变、阴影、文字缩写或过细的拓扑节点，保证在 16px favicon 中仍能清楚识别。

侧栏图标尺寸为 28px，标题与图标之间保持 10px 间距。移动端抽屉使用同一标识，尺寸调整为 24px；图标本身不参与导航项的选中态，也不引入额外装饰。

## 组件与资源

新增一个只负责呈现品牌的 `PlatformBrand` 组件，避免将 SVG 标识复制到侧栏与移动抽屉：

- 默认渲染 28px 图标与“综合靶场平台”文字。
- 提供紧凑尺寸，用于移动端抽屉标题。
- 图形标记使用 `aria-hidden="true"`，名称继续作为可读文本保留。

浏览器图标从同一标识导出为多尺寸 `favicon.ico`，至少包含 16px、32px 与 48px：

- 放在 Next.js `app` 静态元数据约定的位置。
- 利用 Next.js 的 metadata 文件约定生成浏览器需要的 `<link rel="icon">`。
- 不额外引入运行时图标库或图片加载请求。

## 接入范围

修改仅限 Web 前端：

- 管理后台壳层的桌面侧栏品牌区。
- 管理后台壳层的移动抽屉标题。
- 根布局的 favicon 元数据资源。
- 与上述行为对应的前端测试。

不修改 API、认证、导航路由、页面内容或后端服务。

## 验收标准

1. 桌面侧栏顶部在“综合靶场平台”左侧显示 28px 结构盾牌图标，文字与现有边界、间距对齐。
2. 移动端打开导航抽屉时显示同一品牌标识和名称。
3. 浏览器标签页加载本地 `.ico` favicon，16px 时不糊成无辨识度的色块。
4. 深色浏览器标签栏和浅色页面背景中，图标都保持足够对比度。
5. 现有导航、登录态恢复和移动端抽屉交互不回归。
6. 前端构建与相关组件测试在 Docker 容器内通过。
