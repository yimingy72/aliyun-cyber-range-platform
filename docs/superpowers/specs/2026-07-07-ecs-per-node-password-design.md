# ECS 节点级独立密码设计

日期：2026-07-07
状态：Draft

## 1. 背景

当前综合靶场平台中的 ECS 密码仍然走单一全局默认值：

1. 模板编排页没有 ECS 级别的独立密码配置入口
2. 创建实例时，后端统一使用 `OPENTOFU_INSTANCE_PASSWORD`
3. 实例详情页虽然展示密码，但展示的只是全局默认密码或前端兜底文案
4. 无法满足“同一拓扑中每台 ECS 使用不同密码”的场景

用户确认的目标是：

1. 模板编排页中，ECS 属性面板支持设置“自定义密码”
2. 若该字段留空，则每次“生成实例”时都为该 ECS 现场生成新的随机密码
3. 若该字段填写，则该密码保存到模板数据中，后续每次基于模板启动实例时复用
4. 实例详情页要展示该次实例真实使用的密码，而不是全局默认密码
5. 前端输入密码时，按阿里云 ECS 可接受规则做实时校验

## 2. 目标

本次设计覆盖以下能力：

1. 为模板编排页中的每个 ECS 增加可选的节点级自定义密码
2. 为实例创建链路增加“节点级密码解析”能力
3. 支持“留空即随机生成”的实例级密码分配策略
4. 将最终密码持久化到实例运行时数据中
5. 在实例详情页中显示实例真实使用密码
6. 将节点级最终密码传入 OpenTofu 渲染与资源创建链路

## 3. 非目标

本轮不处理以下内容：

1. 不引入第三方 Secret Manager 或加密托管方案
2. 不把密码字段开放给非管理员用户
3. 不在本轮实现“实例运行后在线改密并同步到云主机操作系统”
4. 不在本轮支持模板级批量密码策略
5. 不在本轮支持随机密码历史版本追踪

## 4. 用户确认后的核心规则

### 4.1 模板中的 ECS 密码语义

每个 ECS 节点新增可选字段：

- `customPassword`

规则：

1. 用户显式填写时，`customPassword` 保存到模板拓扑数据中
2. 用户留空时，不在模板中生成默认密码，也不提前写入随机值
3. 模板中“空值”表示“实例创建时随机生成”

### 4.2 实例创建时的密码生成规则

对每个 ECS 节点单独处理：

1. 若模板节点有 `customPassword`，则该节点实例直接使用它
2. 若模板节点没有 `customPassword`，则在本次创建实例时生成一个新的随机密码
3. 随机密码只属于当前实例，不回写模板

### 4.3 实例详情页显示规则

实例详情页始终展示“该实例最终实际使用的密码”：

1. 自定义密码场景：展示模板带下来的密码
2. 随机密码场景：展示本次实例创建时生成的随机密码
3. 历史实例详情与运行中实例详情都可以查看该实例真实密码

## 5. 前端设计

### 5.1 模板编排页 ECS 属性面板

在 ECS 基础信息区中，`CPU / 内存` 下方新增：

1. 字段名：`自定义密码`
2. 输入方式：密码输入框
3. 默认状态：遮挡
4. 交互：右侧提供 `显示 / 隐藏` 切换
5. 辅助说明：
   - `留空时，生成实例会为当前 ECS 自动生成随机密码`

### 5.2 前端实时校验

采用阿里云 ECS 常用密码规则进行实时校验：

1. 长度 8 到 30
2. 不能包含空格
3. 至少包含以下四类中的三类：
   - 大写字母
   - 小写字母
   - 数字
   - 特殊字符

当用户输入不合法密码时：

1. 输入框进入错误态
2. 在字段下方显示错误提示
3. 禁止保存草稿
4. 禁止发布编排
5. 禁止生成实例

### 5.3 实例详情页

实例详情页中：

1. 节点目录的 `账号信息` 继续使用 `账号/密码` 格式
2. 右侧 ECS 属性面板中的密码输入框继续保留，但显示逻辑切换为优先展示实例最终密码
3. 后续若实例详情页继续做实例级密码编辑，可复用相同的遮挡、显示/隐藏、实时校验样式

## 6. 数据模型设计

### 6.1 模板拓扑节点

在 ECS 节点数据结构中新增：

- `customPassword?: string`

该字段进入：

1. 前端 `ScenarioGraphDraft` / `EcsTemplateNode`
2. 模板保存后的 `topologyGraph`
3. 模板运行时转换出的 `scenarioTemplateSpec`
4. 模板编译后的 `compiledProvisionSpec`

### 6.2 实例运行时数据

为实例新增“节点最终密码”持久化字段，建议放在实例运行时快照语义下，例如：

- `runtimeCredentials?: { [hostKey: string]: { username: string; password: string } }`

要求：

1. 该字段属于实例级数据，不属于模板
2. 每次启动实例时生成并持久化
3. 历史实例保留，便于详情页查看

### 6.3 详情接口返回

实例详情接口返回：

1. 节点运行时快照
2. 节点最终密码映射

前端不再依赖全局 `defaultInstancePassword` 兜底显示。  
`defaultInstancePassword` 只在迁移期短暂保留，最终应移除。

## 7. 编译与创建链路设计

### 7.1 模板保存 / 发布

模板保存或发布时：

1. 若 `customPassword` 为空，不报错
2. 若 `customPassword` 非空，必须通过前后端密码规则校验
3. `customPassword` 进入模板拓扑数据

### 7.2 创建实例时的密码解析

创建实例时新增“节点密码决策”步骤：

1. 遍历模板中的 ECS 节点
2. 对每个节点读取 `customPassword`
3. 若有值，直接采用
4. 若为空，调用随机密码生成器生成新密码
5. 生成 `hostKey -> password` 的最终映射
6. 将映射保存到实例运行时数据

### 7.3 OpenTofu / Renderer

当前链路使用单一 `instance_password`。  
本次改造后需切换为“每个 host 单独密码”的渲染模式。

要求：

1. `compiledProvisionSpec` 中增加每个 host 的最终密码信息
2. provisioner 在 prepare/render 阶段读取 host 级密码映射
3. renderer 输出 host 级密码变量，而不是单一全局密码
4. OpenTofu root wrapper 和模块输入需要支持“多主机密码”

### 7.4 全局默认密码的后续角色

`OPENTOFU_INSTANCE_PASSWORD` 调整为：

1. 兼容旧模板或异常场景的兜底值
2. 不再作为正常主路径下所有 ECS 的统一密码

正常主路径必须以“节点最终密码映射”为准。

## 8. 随机密码生成策略

### 8.1 生成时机

随机密码只在“创建实例”动作发生时生成，不在模板保存阶段生成。

### 8.2 生成要求

随机密码生成器需满足：

1. 满足阿里云 ECS 密码规则
2. 默认长度建议 16
3. 包含大写、小写、数字、特殊字符
4. 同一实例内每台 ECS 独立生成

### 8.3 持久化

随机密码一旦生成后，立即与实例记录一起保存。  
同一实例后续刷新详情页时必须看到同一个密码。

## 9. 安全边界

本轮采用管理员后台内的明文管理模式，原因是：

1. 当前功能范围是后台受控靶场平台
2. 实例详情页本身就承担运维查看语义
3. 用户当前明确要求在实例详情中可见密码

但仍需遵守以下边界：

1. 仅管理员后台接口返回密码
2. 靶场实例列表页不直接展示所有密码
3. 日志中禁止打印明文密码
4. 测试输出禁止将真实生产密码写入仓库

## 10. 迁移策略

### 10.1 旧模板

旧模板默认没有 `customPassword` 字段。  
迁移后解释为：

- 所有 ECS 在创建实例时按“随机密码模式”处理

### 10.2 已有实例

已有实例若没有节点级最终密码数据：

1. 在短迁移期内可继续回退到全局默认密码展示
2. 新创建实例一律写入节点级最终密码
3. 待新链路稳定后，逐步移除全局默认密码展示回退

## 11. 测试策略

### 11.1 前端

1. ECS 属性面板显示 `自定义密码`
2. 显示 / 隐藏切换正常
3. 非法密码实时报错
4. 合法密码可保存
5. 留空时不报错，并显示“将随机生成”的说明
6. 实例详情页显示实例真实密码

### 11.2 后端

1. 模板保存时，合法自定义密码通过
2. 模板保存时，非法自定义密码被拒绝
3. 创建实例时，空密码节点会生成随机密码
4. 创建实例时，已配置自定义密码的节点复用该密码
5. 多 ECS 场景下，各节点最终密码可不同
6. 详情接口返回节点最终密码数据

### 11.3 Provisioner / OpenTofu

1. 节点级密码能正确写入渲染产物
2. 多主机场景下，每台主机使用自己的密码
3. 旧模板在没有 `customPassword` 时仍可正常创建

## 12. 分阶段实施建议

### 阶段 1：模板与实例数据模型

1. ECS 节点增加 `customPassword`
2. 实例增加节点最终密码映射
3. 详情接口返回实例最终密码

### 阶段 2：编排页与详情页 UI

1. 编排页新增 `自定义密码`
2. 实时校验
3. 显示/隐藏按钮
4. 实例详情页切换到显示实例最终密码

### 阶段 3：创建链路与 OpenTofu

1. 创建实例时生成节点最终密码映射
2. 将映射传入 compiled spec / provisioner / renderer
3. 完成云上实例节点级密码创建验证

## 13. 结论

本次改造的核心原则是：

1. 模板只保存“用户明确填写的自定义密码”
2. 空值语义固定为“实例创建时随机生成”
3. 实例详情展示“该实例真实使用密码”
4. 后端主路径从“全局单一密码”升级为“每个 ECS 一份最终密码”

这是后续继续扩展“实例级改密”“节点级账号策略”“密码托管/SecretRef”能力的最稳妥基础。
