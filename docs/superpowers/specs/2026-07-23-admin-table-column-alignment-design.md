# 后台表格列宽与页头对齐设计

## 目标

统一后台工作台的桌面端表格列定位，消除操作列占用过多空白的问题；保持表头和操作按钮在同一列的左边界对齐。将当前登录用户与退出入口固定在主内容区域的右上角。

## 范围

- 共享表格列契约和渲染逻辑。
- 镜像中心、靶场编排、编排实例、实例管理和用户管理的操作列。
- 镜像中心的平台镜像与我的镜像的同列宽一致性。
- 桌面与移动端页头中登录状态的位置。
- 对应的前端测试、Docker 构建和容器态视觉验证。

不改变接口、业务数据、权限判断、按钮行为或移动端导航交互。

## 设计

### 列宽契约

`AdminDataColumn` 增加可选宽度字段。`AdminDataTable` 以固定表格布局渲染 `colgroup`，将每列的宽度与响应式隐藏规则共同应用到列、表头和数据单元格。

功能页面拥有各自的列宽定义：

- 平台镜像与我的镜像共用 `ASSET_COLUMNS`，因此字段顺序和宽度完全一致。
- 靶场编排的操作列宽度覆盖“进入编排”和更多操作。
- 编排实例的实例列表、实例历史分别为自身按钮组合声明宽度。
- 独立实例和用户管理的操作列仅保留实际控制项需要的空间。

所有操作列表头和单元格均采用左对齐。金额和其他明确的数值列可以继续使用右对齐，不受此调整影响。

### 页头锚点

页头中的当前登录用户与退出按钮容器在桌面端使用右侧锚点，并与主内容区右内边距对齐。小屏幕下保持现有折叠导航和换行布局。

### 响应式规则

现有的列优先级隐藏断点保持不变。操作列始终是主列；在可见列减少时，其已声明的宽度仍用于对齐按钮，剩余宽度由业务主要字段承接。

## 验收

1. 登录用户与退出按钮显示在桌面端主内容区右上角。
2. 平台镜像和我的镜像切换后，可见的相同字段位于同一横向位置。
3. 靶场编排、编排实例、实例管理和用户管理的操作列在最右侧，但不会形成大面积右侧空白。
4. 每张表的“操作”表头与该列按钮左边界对齐。
5. 实例列表和实例历史都遵循上述操作列规则。
6. 重点组件测试、镜像构建和已运行 `web` 容器验证通过。

## 风险与回滚

列宽仅影响显示层。若某个窄屏场景出现内容截断，可调整该页面的列宽定义或优先级，不需要回滚接口或服务端行为。
