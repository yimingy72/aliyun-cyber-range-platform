# 模板编辑器控件统一设计

## 目标

统一靶场编排模板编辑器的顶部命令区和属性面板选择控件，使其与后台其他页面使用同一套按钮层级、表面颜色、边框和焦点状态。

## 范围

- 顶部命令按钮：
  - `删除选中` 使用红色描边的危险次级按钮。
  - `检测与保存` 使用标准描边次级按钮。
  - `发布到平台` 是唯一蓝色主按钮。
  - 三个按钮保持现有行为、禁用条件和文案。
- 属性面板的 `AdminSelectField`：
  - 选择框与文本输入框使用相同的白色背景、边框、圆角、高度和焦点环。
  - 选择框菜单继续沿用 Radix 的可访问交互、选中状态和禁用状态。
  - 下拉箭头仅表达可选择性，不使用浅蓝填充区分选择框。
- 共享选择控件样式的调整会同步改善当前使用 `AdminSelectField` 的账单筛选、用户角色和镜像上传表单。

## 非目标

- 不修改移动端样式或断点规则。
- 不调整拓扑编辑、模板保存、发布、删除、权限或 API 调用逻辑。
- 不改变字段名称、选项、默认值或提交 payload。

## 实现边界

- 使用现有 `Button` 的 `default`、`outline` 和 `destructive` 变体，不新增局部按钮实现。
- 在 `apps/web/components/ui/select.tsx` 收口共享选择控件的视觉语言。
- 模板属性面板继续通过 `AdminSelectField` 适配，不引入第二套选择控件。
- 所有变更限制在桌面控件表面与工具栏层级；不添加移动端 CSS 覆盖。

## 验证

- 更新模板编辑器测试，断言三种按钮变体及现有禁用行为。
- 更新共享选择控件测试，断言触发器与输入框共享的表面样式约定，以及空值和禁用态行为不变。
- 使用 Docker 构建 `web` 镜像并在容器中运行受影响前端测试。
- 只重建 `web` 容器并在容器态复核模板编辑器页面。
