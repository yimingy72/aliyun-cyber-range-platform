# 管理员登录首页极简化设计

日期：2026-07-10  
状态：Draft

## 背景

当前管理员登录首页承载了过多非必要信息：

1. 左侧品牌说明区
2. 在线状态与阶段能力说明
3. 顶部后台标签组
4. 重复的引导文案

这些信息和登录动作本身没有直接关系，导致页面视觉层级分散，首屏焦点不够明确。

## 目标

将管理员登录首页收敛为一个极简单栏登录页：

1. 让用户进入页面后第一眼只看到登录动作
2. 只保留必要的品牌识别，不保留冗余说明
3. 与当前后台 UI 语言保持一致，但显著降低信息密度

## 非目标

本次不处理：

1. 登录接口与认证逻辑
2. 表单字段含义与提交行为
3. 跳转目标与会话存储
4. 选手登录页改版

## 已确认方向

用户已确认的设计方向：

1. 采用 `极简单栏`
2. 页面中只保留 `平台名称`
3. 不保留额外说明性文案块

## 页面结构

管理员登录页改为单栏居中布局：

1. 页面主体仅保留一个居中的登录面板
2. 面板内部从上到下依次为：
   - 平台名称 `综合靶场平台`
   - 标题 `管理员登录`
   - 管理员账号输入框
   - 登录密码输入框
   - 错误提示
   - 登录按钮

删除以下结构：

1. 左侧 `admin-login-sidebar`
2. 顶部 `admin-login-topbar`
3. “访问入口 / 在线 / 当前阶段能力”等状态区
4. “工作台 / 靶场编排”“角色 / 管理员”等标签组
5. 额外描述性段落

## 视觉方向

整体视觉采用“干净、正式、克制”的后台登录页风格：

1. 页面背景使用轻量浅色背景，不制造复杂信息块
2. 登录面板使用白底、圆角、细边框和轻阴影
3. 平台名称作为最上方品牌识别，权重高于说明文字
4. `管理员登录` 作为表单标题，层级低于平台名称但高于字段标签
5. 字段间距、面板内边距、按钮高度统一，不出现多余装饰元素

## 行为要求

以下行为保持不变：

1. 默认账号仍为 `admin`
2. 登录失败提示逻辑保持不变
3. 登录成功后仍跳转到 `/admin/scenarios`
4. 提交中按钮仍显示 `正在登录...`

## 可访问性与兼容性

1. 保留现有表单语义与 `aria-label`
2. 错误提示继续使用可见文本反馈
3. 在常见桌面分辨率下保持居中与稳定留白
4. 在较窄宽度下，面板应自然收缩，不出现横向溢出

## 实现范围

优先最小改动：

1. 主要修改 `apps/web/components/auth/admin-login-screen.tsx`
2. 配套调整 `apps/web/app/globals.css` 中登录页相关样式
3. 不新增依赖，不引入新组件层

## 验证要求

### 视觉验证

1. 页面首屏只剩单栏登录面板
2. 平台名称保留，其余杂乱信息删除
3. 输入框、按钮和错误提示排列整齐

### 功能验证

1. 正常输入账号密码可登录
2. 错误密码时仍显示原有失败提示
3. 提交中按钮状态正常

## 风险与控制

主要风险是样式清理时误伤其他后台布局。

控制方式：

1. 只改登录页专用类名对应样式
2. 不调整通用后台容器的基础语义
3. 完成后做登录页与后台其他页面的快速回归
