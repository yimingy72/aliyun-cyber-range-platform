# 拓扑编辑工作台空间与全屏属性面板设计

## 状态

交互设计已确认，等待 Spec 审阅与实施计划。

## 背景

模板创建和编辑页复用管理工作台的顶部栏。该栏主要包含当前登录用户与退出登录操作，但在桌面拓扑编辑场景中占用垂直空间，降低画布可见区域。

当前全屏编辑仅让 `.topology-flow-workbench` 进入浏览器全屏层。属性面板是 `.template-editor-grid` 内与工作区同级的元素，因此虽然新增资源和点击节点仍会选中节点，却无法在全屏层中显示属性面板。

此外，React Flow 当前将空白处左键拖动用于框选，并只允许中键拖动平移，和“选择模式下通过空白处拖动画布调节视图”的预期不一致。

## 目标

- 在桌面模板创建和编辑页隐藏管理顶部栏，为画布释放垂直空间。
- 进入全屏编辑后，继续支持新增资源或点击节点并显示属性面板。
- 选择模式下，允许在画布空白处用左键拖动平移视图。
- 保持节点点击选择、`Shift` 多选、连线、保存、草稿缓存和移动端行为不变。

## 非目标

- 不隐藏模板列表、镜像中心、实例管理或其他管理页的顶部栏。
- 不改变移动端顶部栏、导航入口或响应式布局。
- 不重写属性表单、保存、检测、发布、历史记录或拓扑数据。
- 不保留空白处直接框选；本轮不新增替代的拖拽框选手势。

## 桌面编辑页顶部栏

`AdminWorkspaceShell` 根据当前路径识别模板编辑路由：

- `/admin/scenarios/new`
- `/admin/scenarios/:scenarioId`

仅在桌面断点为工作台根元素添加编辑页数据标识，并以 CSS 隐藏整个 `.admin-topbar`。左侧导航与模板编辑器自己的名称、删除、检测保存和发布操作保持可见。

移动端不使用此隐藏规则，仍保留现有导航入口和顶部栏。

## 全屏目标与属性面板

全屏目标从 `.topology-flow-workbench` 提升到其最近的 `.template-editor-grid`：

1. 点击全屏按钮时，画布读取最近的编辑网格并调用该元素的 `requestFullscreen()`；没有网格容器时回退到工作区本身，保证组件测试与独立使用仍可工作。
2. `fullscreenchange` 以当前实际目标是否为 `document.fullscreenElement` 为唯一状态来源。
3. `.template-editor-grid:fullscreen` 使用 `100vw × 100vh` 且 `min-height: 0` 占满视口，内部 `.topology-flow-workbench` 同步使用 `min-height: 0` 填满网格，不能继承普通编辑的 `680px` 最小高度。
4. 同级 `TemplatePropertyPanel` 仍属于全屏网格，保持其现有覆盖式位置和关闭行为。
5. 新增资源已由编辑器选择新节点并打开属性面板；本轮只修复全屏层不包含面板的问题，不改变该领域行为。

退出全屏后，网格、属性面板和画布恢复原有普通编辑布局。浏览器 `Esc` 继续由 Fullscreen API 退出，不被画布快捷键拦截。

## 选择模式的空白处拖动

画布按模式配置平移：

- 选择模式：`panOnDrag` 启用左键和中键，空白处左键拖动平移世界视图。
- 连线模式：保留中键平移，避免左键手势与创建连线竞争。
- `selectionOnDrag` 关闭，因此空白处拖动不再绘制框选区域。
- 现有点击节点选择、`Shift` 多选、`Space` 加拖动平移和滚轮缩放保持不变。

## 样式与可访问性

- 顶部栏仅通过桌面限定选择器隐藏，不从 DOM 删除，因此认证、会话续期和退出登录逻辑不受影响。
- 全屏按钮继续根据实际浏览器全屏状态提供动态名称、标题和 `aria-pressed`。
- 属性面板在全屏时保留焦点顺序、关闭按钮和现有桌面尺寸。
- 全屏的导航图与开关定位规则以全屏网格为边界，保留对属性面板的避让，不能继续依赖工作区自身成为全屏元素。
- 不新增移动端样式调整。

## 测试策略

先以失败测试定义行为：

- 管理工作台测试：模板创建和编辑路由在桌面标识为沉浸式编辑页；模板列表和其他路由不受影响。
- 画布测试：在 `.template-editor-grid` 包装下，全屏请求目标为编辑网格；无包装时回退到工作区；`fullscreenchange` 仍同步按钮。
- 画布测试：选择模式传入左键和中键平移配置且不启用框选；切换到连线模式后恢复中键平移。
- 编辑器回归：新增资源仍自动选择节点并打开属性面板。
- 样式契约：桌面编辑页隐藏顶栏，`.template-editor-grid:fullscreen` 与内部工作区尺寸规则存在，且不引入移动端覆盖。

## 容器验证

实现后重建 Web 镜像，并在 Docker 容器中运行模板编辑器、画布和工作台相关 Vitest。使用已登录浏览器进行不保存的页面验收：

1. 桌面创建和编辑页不显示管理顶部栏，列表页仍显示。
2. 全屏后新增资源或点击节点，属性面板显示并可关闭。
3. 选择模式下左键拖动空白处平移画布；节点拖动仍移动节点。
4. 连线模式和显式保存前的草稿行为不回归。

不执行保存、检测、发布、创建或销毁云资源操作。
