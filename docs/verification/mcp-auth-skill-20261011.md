# MCP、接口鉴权与平台 Skill 审核

本轮基于已部署的平台功能审核网关、90 个 MCP 工具、平台 SDK、对应 API 权限边界和七个产品模块的 Skill。新增业务功能的操作合同已同步；本轮没有创建或销毁云资源，也没有调用账单同步或重置真实用户权限。

## 修复

| 范围 | 问题与最终行为 |
|---|---|
| 网关身份 | 删除静态 Bearer、共享管理员令牌和管理员 OAuth 客户端回退；必须验证签名、issuer、audience、有效期及签名中的客户端身份。每个请求重新核对平台用户启用状态和角色，不跨用户复用 session、Token 或工作空间。 |
| 令牌交换 | 交换结果再次验签，并核对同 issuer、同 subject、网关客户端及 API audience。显式业务 scope 与当前角色取交集，交换不得扩权；未知 scope，包括不含冒号的未知值，不能回退到完整角色权限。空 scope 或已知身份 scope 保持现有 Keycloak 登录兼容。 |
| HTTP 边界 | Host/Origin 精确匹配 loopback、公开地址及显式允许列表；不信任任意转发 Host。拒绝重复或歧义的鉴权与工作空间请求头。补充公开的 OAuth protected-resource 元数据及 Caddy 路由。Compose 显式允许内部 `mcp:8787`。 |
| API 权限 | API 自行校验已验证的委托 scope，不能仅依赖 tools/list 的隐藏。读取权限不能调用销毁、账单同步、账号切换或镜像打包；凭据与 VNC 需要额外凭据 scope。关闭未暴露的旧编排创建、镜像上传/完成导入/旧收录入口，以及原始作业步骤日志入口。 |
| 凭据隔离 | 普通 MCP 和显式受限 Web 元数据响应递归清除密码、运行凭据、SSH/VNC、AK/SK 等敏感字段；专用访问接口仍需 scope、角色和所有权校验。保留预览令牌、日期、资源身份及脱敏任务证据。 |
| 工具合同 | 顶层未知参数拒绝，管理员工具要求明确 admin 角色，修正打包/VNC/网络回收等复合 scope 和操作注解；腾讯云账号兼容别名按真实绑定流程执行。 |
| 并发编辑 | 模板编辑与保存必须传调用者刚读取的版本；运行草稿保存、丢弃、预览、应用与同步使用准确草稿版本。新增 `range_instance_topology_discard`；同步仅引用已保存草稿，不再隐式保存新图。后端保留当前资源中未修改的私有密码，不要求调用者先获取凭据。 |
| CSV | 账单字符串元数据防止电子表格公式执行，金额和负退款保持数字；实例凭据 CSV 逐台通过受控访问接口获取，不从普通列表提取密码。 |
| 验证脚本 | compose 与 SDK smoke 只使用已有令牌和现有 Docker MCP 容器；删除自动登录、SQL 创建/提升管理员和启动服务行为。拒绝写操作、凭据、VNC、实例凭据 CSV，成功与失败都不回显业务结果。 |

## Skill 与客户端说明

- 项目 `skills/` 为维护来源；按用户操作意图选模块，不再由“VPC/模板/DNS”等关键词强迫只读请求进入创建流程。
- 补齐动态拓扑草稿、预览、应用、丢弃、另存、同步、DNS 核验、多云账号与工作空间、平台费用归属和待出账状态。
- 区分用户持续授权与服务端二阶段确认；已获准确授权的受控操作不重复要求相同人工确认，仍须核对服务端摘要、版本、稳定幂等键和最终作业结果。
- 明确 CPU/内存转换，系统 DNS 配置不写入用户 `initScript`；不把待出账解释为免费，也不声称尚未实现的 DNS/账单页面改版已经上线。
- Codex 已安装的旧版 69 工具 Skill 已完整备份，同步项目正文、参考和多云界面入口；未修改其它 Skill。
- 接入方需重新读取 `tools/list`，尤其版本参数、草稿同步输入及凭据 scope 的变化。静态令牌接入已移除，改用现有启用用户的 OIDC Token。

独立 Skill 正向评估覆盖六类请求、21 个离线工具调用计划。资源版本、预览令牌和作业 ID 必须绑定真实响应；不能复用旧 fixture 的版本或猜测 Token。

本轮不增加新业务 UI，不升级 MCP SDK 主版本，不以原始任务日志或云账号聚合费用替代受控证据。读取模型和权限边界测试通过，不代表所有云资源写操作在本轮重新实测。
