# 桌面前端性能验证

在相同的 Docker 演示数据上对照优化前（`75dc1e6b`）和优化后生产构建。Chromium 使用 1440 × 960 视口和 4 倍 CPU 降速，每个页面从新浏览器上下文冷启动三次，取中位数。脚本列是浏览器实际收到的压缩 JavaScript 大小；请求列包含登录会话和当前工作空间的读取。

| 页面 | 首屏压缩脚本（前 → 后） | 减少 | 首屏 API 请求（前 → 后） |
| --- | ---: | ---: | ---: |
| 登录 | 313 → 116 KiB | 63% | 0 → 0 |
| 基础配置 | 309 → 180 KiB | 42% | 3 → 3 |
| 镜像中心 | 309 → 214 KiB | 31% | 7 → 7 |
| 实例管理 | 309 → 255 KiB | 17% | 5 → 3 |
| 靶场编排 | 309 → 225 KiB | 27% | 3 → 3 |
| 编排实例 | 309 → 240 KiB | 22% | 3 → 3 |
| 用户管理 | 309 → 192 KiB | 38% | 3 → 3 |
| 账单费用 | 309 → 228 KiB | 26% | 4 → 4 |
| 编排实例详情（节点目录） | 413 → 273 KiB | 34% | 5 → 3 |
| 模板拓扑编辑器 | 391 → 267 KiB | 32% | 5 → 5 |

加载时间在不同轮次有波动。基础配置隔离复测的首次内容绘制（FCP）为 972 → 1184 ms，最大内容绘制（LCP）为 1632 → 1476 ms。账单费用的 LCP 在整轮测试为 1748 → 1280 ms，在隔离复测为 1188 → 1608 ms。因此首屏体积的下降可复现，但本地测试不能证明所有页面在实际网络上都更快。

包含 1,041 个节点、1,040 条连线的合成图中，单次网段计算耗时从 9.74 ms 降至 3.70 ms，画布节点转换从 16.35 ms 降至 3.34 ms。数据为容器内函数基准的中位数，不包含浏览器绘制。

- 登录和认证回调独立于工作台加载；工作台按页面拆分，返回时保留筛选、分页和滚动状态。
- 实例列表在打开创建表单或从镜像中心预填时才读取镜像。编排实例默认节点目录不加载画布和镜像目录；打开拓扑时再加载。切走时卸载画布，返回时恢复未保存的草稿。
- 镜像中心只筛选当前来源，浏览器标签页隐藏时暂停导入进度刷新。画布样式随画布加载，网段和连线通过索引查找。
- 默认账单页面延后加载兼容版；账期、金额和导出仍用同一套格式逻辑。
- 容器定向测试通过；Chromium 实测了经典和赛璐璐主题下的七个工作台、列表返回、实例草稿恢复、私有镜像预填和画布样式。
