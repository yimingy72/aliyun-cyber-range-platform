# 腾讯云执行与费用集成

开发分支 `codex/tencent-cloud`。沿用按厂商、主账号 UID 隔离的工作空间，保存账号与切换数据分别操作。

## 执行路径

腾讯云单实例由 OpenTofu 批次模块创建和销毁；原账号、地域、可用区、owner、资源清单与创建意图在受理时冻结。使用定制 provider `1.83.34-range.1`，固定 SHA-256 为 `d6537266986c80b5c936cf84be3d8bbca31b1e1249277ced332399a3c65f4535`。CVM 请求携带持久 ClientToken 和原子云端到期终止时间；EIP 使用持久 ClientToken，平台 NAT 未知创建结果禁止自动重复创建。

腾讯云模板编译与编排模块已接入。真实编排开通默认关闭：`TENCENTCLOUD_RANGE_NAT_EXECUTION_ENABLED=0`，工作空间 `capabilities.rangeProvisioning` 同步反映此状态。腾讯云 NAT 严格 SNAT 模式不能通过当前创建接口配置，DNAT 网段必须同时启用 SNAT，保存阶段明确拒绝不兼容设计。

回收使用原始来源与原状态工作区。云资源来源、标签和精确 ID 核对后才允许导入恢复；未知 NAT/EIP 只能恢复原资源并销毁，不继续 apply 补建。所有活动计费台账的资源均须独立确认消失，不能只凭 OpenTofu 成功或摘要为空释放费用记录。恢复和销毁不受新开通开关影响。

## 镜像与费用

公共/自定义镜像目录、收录、打包与依赖快照清理均使用对应厂商和原账号。新单实例仅接受可用 x86_64 系统盘镜像，并实时核对系统盘容量；不支持带数据盘的创建镜像。导入显式核对官方发行版/版本，COS 私有专属桶、上传对象和镜像任务保留独立来源证明。

官方 [Image 数据结构](https://intl.cloud.tencent.com/document/product/213/15753?has_map=1) 允许 `SnapshotSet` 返回 `null`，真实公共镜像的 MCP 前置检查已观察到该字段省略。创建前置校验仅对已明确为 `PUBLIC_IMAGE`、`NORMAL`、`x86_64` 且有有效整数 `ImageSize` 的镜像接受显式 `null` 或字段省略。自定义镜像仍要求快照数组可核验，缺失或空值、任何数据盘、未知盘用途或异常结构均拒绝。前置拒绝返回安全的字段分类和 409，不包含镜像 ID、SDK 原始响应或凭据，便于 MCP 在创建网络前定位契约差异。

官方 DescribeBillDetail 明细按 UTC+8 账日、收费组件和精确来源资源归属，保存退款符号与币种。仅平台创建资源计入平台费用；外部资源、混用桶和账号汇总不归入平台，来源或明细不完整时保留待对账提示。CVM、CBS、NAT、EIP、平台镜像依赖快照及专属 COS 桶均有对应核验路径，详见 Skill 的账单参考。

## 验证与运行边界

验证通过 Docker、隔离 PostgreSQL、synthetic 云响应与离线 OpenTofu 完成；不将离线 50 台 plan 当成真实云开通性能。真实数据库备份恢复迁移演练保留 27 张原业务表的 4,607 条记录；固定历史账日的平台费用和创建来源证明前后一致。

腾讯云账号加密绑定、真实 CVM/COS 权限、最小单实例及编排创建/销毁和延迟账单核对需要分别执行真实平台验证。目前不声称已通过这些云上测试，编排开通保持关闭。保存账号不会创建云资源或切换当前阿里云数据。

CVM 的云端到期终止不会自动删除 NAT、EIP 或 COS。worker 停机期间这些资源可能继续计费；需要持续运行恢复 worker 并跟踪逐资源回收终态。完整状态与创建证明同时丢失时禁止自动接管或重建，需原账号 CloudAudit 或人工提供精确来源证据。

历史开发记录 `2026-10-09-tencent-cloud-development.md` 仅描述前一批只读接入；当前能力以此记录和运行时 capabilities 为准。
