# 云厂商账号工作空间

## 数据与切换

`CloudWorkspace` 按云厂商和主账号 UID 唯一。账号的不同地域配置是同一空间下的 `CloudAccountContext`；默认地域与可用区由该空间的 `activeCloudAccountContextId` 指定。

镜像、镜像标签、模板、单实例批次、编排实例、用户、账单、任务、确认记录、幂等和审计均带工作空间归属。服务端在验证登录身份后解析空间，并以 AsyncLocalStorage / Prisma 查询约束执行读写隔离。跨空间 ID 访问、关联或修改被拒绝，不依赖前端过滤。

基础配置按厂商筛选已绑定账号，可新增或编辑账号配置。保存不会切换数据，编辑时凭据必须属于目标主账号。点击「切换到此账号」后显式加载该空间的数据；切回后恢复原数据。腾讯云镜像查询归镜像中心。

平台超管拥有统一身份，可管理绑定与切换全部空间。业务管理员和用户归属各自空间；同名业务用户使用独立的登录账号、OIDC 身份和密码。旧登录账号不变，用户列表提供新登录账号的查看与复制。业务管理员不能管理平台超管。

Web 请求显式携带 `x-cloud-workspace-id`，每个窗口保存自己的选择；无显式请求头时使用登录用户的默认空间。非法选择不会回退到其它账号。切换同时清理页面状态与缓存，模板本地草稿按用户和空间分开，旧异步响应不会覆盖新页面。

## 后台与凭据

任务受理时冻结空间、账号 context、主账号 UID、地域、可用区和所有者。后台全局只发现任务，实际创建、回收、过期处理、镜像与快照处理均在原空间执行，页面切换不改变任务来源。

账号配置可以更新同一主账号的默认地域/区；已受理任务继续使用其冻结值。新绑定及更新的阿里云、腾讯云 Secret 均使用 AES-256-GCM，并绑定厂商、UID、地域和 SecretId。旧阿里云明文凭据保持读兼容，不自动修改；加密密钥沿用受保护的 `CLOUD_CREDENTIALS_ENCRYPTION_KEY`。

账单定时同步逐个已验证、可执行的阿里云与腾讯云空间运行。不同空间的相同幂等键、镜像 ID、模板名、账单指纹不会相互覆盖。腾讯云已接入单实例、镜像生命周期与费用同步；编排真实开通另外受独立能力标志控制，默认关闭，需受控回收实测后启用。代码回归通过不代表真实云上资源和费用已完成验证。

## 旧数据迁移

第 42 个迁移 `20261009230000_cloud_workspaces` 基于真实账号 UID、冻结 context、台账和镜像导入/打包的精确引用分配空间。保留原资源 ID、owner ID、source job、云标签和云状态。平台目录归属不等于云资源创建或费用归属。

无法核实或存在冲突的来源记录留在只读的 `legacy-unbound` 历史空间。模板、标签及旧业务用户按可证明的数据集引用或原活动阿里云平台数据集迁移；不将这些元数据当作云资源所有权证明，不复制到新腾讯云空间。

部署前备份数据库；迁移回归仅使用 Docker 独立测试库。真实平台资源操作继续经 MCP。迁移不创建或删除云资源，旧缺少来源证明的云资源仍需核验后恢复，不能据迁移成功声称已回收或费用全部对齐。

## 容器验证

```sh
bash scripts/ci/verify-docker.sh
```

CI 创建独立的工作空间隔离与历史迁移测试库，执行服务端跨空间读写、并发、用户/OIDC、确认重放、后台冻结来源、前端缓存和请求头回归，以及生产构建和 IaC 检查。部署时保留现有 OpenTofu 工作空间卷及凭据加密密钥；API、worker、Web 和 MCP 使用同一源码版本。
