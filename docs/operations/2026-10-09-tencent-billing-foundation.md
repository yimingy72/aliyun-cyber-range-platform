# 腾讯云账单来源与跨云隔离基础

本批次提供腾讯云官方账单的只读客户端和跨云隔离保护。腾讯云账单尚未接入平台入账、对账、导出或定时同步；腾讯云账号保持未启用。当前阿里云账单功能继续使用已有平台创建来源证明。本批次没有创建云资源，也没有使用真实密钥请求账单。

## 已实现的边界

- `BillingBssClient` 的账单与分账两个入口，以及 `BillingSyncService` 的同步入口，只接受明确的 `alibaba_cloud` 上下文。腾讯云、未知厂商或缺失厂商在签名和台账读取/写入前拒绝；既有账单继续保留。
- 编排资源创建证明同时核对实例与台账的云厂商、冻结账号 UID 和地域。两个云厂商即使出现相同 UID、地域字符串及资源 ID，也不能相互认领。
- 现有镜像打包/导入来源记录仅代表阿里云创建链，不能证明腾讯云快照或镜像的来源。阿里云历史来源修复不会修改腾讯云台账。
- 新阿里云费用和异常行保存 `rawPayload.__platformCloudProvider=alibaba_cloud`，同步批次 ID 包含厂商。旧无厂商标记的费用只能关联阿里云台账；腾讯云和未知厂商标记拒绝进入阿里云汇总、用户分组、明细及 CSV。
- `TencentBillingClient.listMonthlyBillingItems` 要求明确的腾讯云上下文和已验证数字 UIN；每页沿用方法开始时捕获的凭据和账号。客户端只返回来源记录，不写数据库。

## 官方账单接口核验

使用中国站 `billing.tencentcloudapi.com` 的 `DescribeBillDetail`，版本 `2018-07-09`，按 `Month` 请求，`Limit=300`、`Offset` 递增，并带 `NeedRecordNum=1` 和已验证的 `PayerUin`。官方文档说明时间起止参数仍返回整月数据，因此不能将它当作阿里云的每日同步接口；`Total` 每 24 小时缓存且可能少于实际记录，分页必须读到短页结束，再检查实际数量至少覆盖已报告数量。[官方接口说明](https://cloud.tencent.com/document/api/555/19182)

每条来源记录检查 `OwnerUin` 与 `PayerUin`、`BillDay`/`BillMonth`、记录 `Id`、资源 `ResourceId` 和数字地域 `RegionId`；重复记录、缺页、变化的总数、错误账号、无效费用及后续请求失败均丢弃本次不完整结果。使用组件 `RealCost` 的 Decimal 精确求和保留负退款；现金、代金券、赠送金和原价字段不重复相加。数字账单地域保留为 `billingRegionId`，不猜测转换为 `ap-*`；本客户端限定中国站人民币来源。[官方数据结构](https://cloud.tencent.com/document/product/555/19183)

`DescribeBillResourceSummary` 可提供资源汇总 `RealTotalCost`，但汇总没有组件级交易证据，本批次不使用它替代明细或作最终入账依据。[官方资源汇总接口](https://cloud.tencent.com/document/api/555/19181)

## 启用真实入账前仍需完成

1. 费用行、异常行、按日替换及唯一键增加显式云厂商维度，禁止只用账号 UID 清除另一个云厂商的记录。
2. 腾讯云创建/销毁台账和镜像、快照、COS 创建来源链都必须带厂商、原账号及原地域；云标签或收录现有镜像仍不能代替创建证明。
3. 官方数字账单地域与执行地域建立可核验的对应关系；按真实 `BillDay` 归账，不能把整月费用反复计入每天。
4. CVM、磁盘、EIP、NAT、快照、COS 等计费产品及资源 ID 逐项验证；混用 Bucket、账号级汇总或来源不明的费用保留待核对，不估算归属。
5. 腾讯云创建、销毁、延迟出账、退款和多用户/多账号隔离的容器测试及受控真实验证通过后，才能开放账号启用与真实资源创建。

## 本批次验证

基于 `range-tencent-billing:validation` 镜像，在 `--network none` 的 Docker 容器中完成 12 个账单相关测试套件、180 个测试及 API 生产构建。覆盖腾讯云/未知云凭据禁止发送给阿里云、同步失败前账单保留、跨云相同资源 ID 碰撞、历史费用厂商标记、阿里云快照来源不得认领腾讯云快照、腾讯月账单分页、缓存总数偏小、退款精度、账号冻结及后续页失败。

本批次没有进行真实腾讯云账单或资源操作；本地纯模拟证明不等于腾讯云费用端到端对齐。独立只读客户端没有注册为平台同步器，上线接入时仍须纳入官方每秒 5 次的调用预算。
