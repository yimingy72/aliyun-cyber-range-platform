# 修改实例回收时间

阿里云单实例、单实例批次、编排实例和编排批次的操作菜单提供“修改回收时间”；编排详情页在“实例操作”中进入。同一弹窗展示当前时间、精确影响范围、提前/延期、修改记录及原任务核验入口。时间按北京时间输入，接口传带时区 ISO-8601。

- 新时间至少在 30 分钟后，原平台回收时间至少剩余 5 分钟；上限为 1095 天并为云端释放预留 5 分钟及分钟取整余量。云端时间规则见 [ModifyInstanceAutoReleaseTime 官方文档](https://help.aliyun.com/en/ecs/developer-reference/api-ecs-2014-05-26-modifyinstanceautoreleasetime)。
- 只对已创建、来源可证明、无活动任务的阿里云实例执行；创建/销毁中、来源缺失、结果未知的电源任务、未结束的镜像任务、只读空间均阻止修改。腾讯云当前不开放此入口。
- 已有节省停机预约时先显式取消，改期后重新预约；不静默撤销或改变预约。
- 服务端二阶段确认绑定工作空间、操作者、准确成员、新旧时间和源版本。批次的本地任务受理全有或全无，云端执行逐实例报告结果。
- 提前回收在受理时将平台时间缩短；延期只有全部主机的原生释放时间核验成功后才更新平台时间。失败或未知时平台保留较早时间，不取消原自动回收。
- 每台主机仅记录并发送一次原生修改；网络超时或 worker 恢复仅核验原主机，不盲目重发。“核验原任务”不发送云端写请求。原实例已进入其他任务时，旧任务不得覆盖新状态。
- 不操作磁盘、网络、电源或凭据，不调整计费台账。改期产生的额外使用费用仍按原账号及归属统计。

## 实现与回收兼容

change_expiry 为独立 ProvisionJob 类型，API/worker 共用云账号与原生所有权预检。原任务持久记录目标、请求意图、回执和逐主机核验结果。数据库迁移只增补枚举，不重写现有实例。

平台时间和任务受理/终态通过 CAS 与事务提交；自动回收扫描核对当前版本，不能用旧扫描结果销毁已延期实例。资源摘要保存 expiryChangeJobId。后续 OpenTofu 操作只有核对同实例、同空间、同账号和原创建来源的改期记录后，才接受时间字段变化；镜像、主机、网络和创建来源的冻结校验不放宽。

容器回归覆盖四种操作范围、确认与幂等、越权/只读隔离、未知请求恢复、缩短/延长安全语义、原生参数、并发受理、过期扫描竞争、改期后的单实例销毁，以及编排追加主机时的持久时间文件同步。模拟测试不证明真实云账号已具备 ecs:ModifyInstanceAutoReleaseTime 权限。
