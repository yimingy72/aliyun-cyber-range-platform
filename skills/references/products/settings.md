# 基础配置

管理平台的云配置。该产品只限管理员，且配置中可能包含脱敏密钥或影响后续所有云资源操作的默认值。

## 工具与权限

| 操作 | MCP 工具 | Scope |
|---|---|---|
| 查询配置 | `cloud_config_get` | `settings:read` |
| 更新配置 | `cloud_config_update` | `settings:write` |

## 产品内意图路由

| 用户意图 | 工具与流程 | 参数约束 |
|---|---|---|
| “查看当前地域、可用区、网络或云配置状态” | `cloud_config_get` | 只读；脱敏密钥只表示已配置，不能作为可复用值。 |
| “修改默认地域、可用区、网络或云凭据” | [更新流程](#更新流程) | 仅传用户明确要求的配置字段；禁止把读取到的脱敏值回写。 |
| “创建或修改平台资源” | 路由到相应资源产品 | 云配置不是创建实例、模板或镜像的替代入口。 |

## 更新流程

1. 先调用 `cloud_config_get` 获取当前可见配置和字段状态；脱敏值不能视为可复用的真实密钥。
2. 确认用户指定的精确字段、变更值和影响范围，例如地域、可用区、网络默认值或云凭据。
3. 展示配置变更摘要并取得危险操作确认；只传用户要求的字段，不覆盖未提及字段。
4. 调用 `cloud_config_update` 后重新查询并核对非敏感字段。

不得在对话、日志或 Skill 文件中保存 AccessKey、Secret、Token 或其它密钥。详见 [sensitive-outputs.md](../sensitive-outputs.md)。
