# 账单费用

账单费用是平台导航产品域，但当前 MCP Server **未暴露账单或成本查询工具**。

## 产品内意图路由

- “查账单、费用、成本、资源消耗”均进入本产品域。
- 若当前 `tools/list` 未出现账单工具，停止在能力边界；不能借用实例、配置或云厂商工具推算账单。
- 若未来出现账单工具，再按其 schema 将意图细分为查询、筛选、导出或预算操作。

## 处理规则

1. 先以当前 `tools/list` 为准确认是否出现账单工具。
2. 当前未暴露时，明确告知用户 MCP 暂不支持该操作。
3. 不使用 HTTP API、数据库、云厂商 CLI 或浏览器绕过能力边界。
4. 若未来发布账单工具，以其 schema、scope 和本产品参考的后续更新为准。
