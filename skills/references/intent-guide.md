# 意图路由指南

仅在用户表达含糊、同时提到多个资源域，或出现“实例、镜像、关闭、访问、重试”等易混淆词时读取。本文件帮助选产品，不替代当前 MCP schema 或产品流程。

## 资源域判断

| 用户表述 | 路由产品 | 必要澄清 |
|---|---|---|
| “模板、蓝图、拓扑、节点、交换机、NAT、草稿” | [靶场编排](./products/range-authoring.md) | 是设计/编辑模板，还是基于现有模板启动环境？ |
| “整套靶场、环境、编排实例、启动拓扑” | [编排实例](./products/range-instances.md) | 需要模板 ID、名称和到期时间。 |
| “单台靶机、训练主机、CPU、内存、数量、批次” | [实例管理](./products/instance-management.md) | 需要平台镜像、CPU、内存、数量和到期时间。 |
| “镜像、快照、收录、启用、发布镜像” | [镜像中心](./products/image-center.md) | 快照收录、由实例打包，还是资产可见性/可用性管理？ |
| “用户、角色、禁用、重置密码” | [用户管理](./products/user-management.md) | 需要管理员权限和准确 userId。 |
| “费用、账单、成本” | [账单费用](./products/billing.md) | 当前 MCP 是否实际暴露账单工具。 |
| “地域、可用区、云配置、密钥” | [基础配置](./products/settings.md) | 需要明确字段和影响范围。 |

## 易混淆场景

### 创建实例

- 提到模板、靶场、拓扑或整套环境：使用编排实例。
- 提到平台镜像、CPU、内存、数量或单台训练机：使用实例管理。
- 无法判断时，只问一次：要基于模板启动整套靶场，还是基于平台镜像创建独立靶机？

### 镜像

- 纳入已有云快照：镜像中心的收录。
- 从独立靶机生成私有镜像：实例管理的打包。
- 改变平台镜像是否可新建或是否可见：镜像中心的启停或发布。

### 关闭、删除、回收

- 当前平台没有通用“关机”工具；不得将其擅自映射为重启或销毁。
- 确认销毁范围：单台实例、整个批次，还是整套编排靶场。
- 销毁属于危险操作，必须确认并跟踪终态。

### 访问、重试与重启

- 只查状态或非敏感详情：使用对应产品的 `list`/`get`。
- 明确索要密码、SSH、VNC 或凭据 CSV：再读取 [敏感输出规则](./sensitive-outputs.md)。
- `retry` 仅用于创建/销毁失败；`reboot` 仅用于运行中的单实例。
